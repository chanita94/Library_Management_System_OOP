#Library Management System

##About the Project

###The Library Management System is a console application developed in C#.
###The project simulates a library system where different types of library items can be managed, and members can borrow and return items.
###The main purpose of this project is to demonstrate OOP and SOLID principles, exception handling.

##Project Structure

##The application is organized into separate folders to maintain a clear separation of responsibilities.
##Models – Contains the main entities, including library items and people.
##Interfaces – Defines contracts for shared functionality.
##Services – Handles the library's business logic and operations.

##Object-Oriented Programming (OOP)
###Inheritance:  Creating sub classes (Book, DVD, Magazine) and (Employee and Member) based on common base classes (Item and Person).
###Encapsulation: Protecting data through properties, access modifiers, validation, and controlled access to collections.
###Abstraction: Defining common behavior and hiding implementation details through abstract classes and interfaces.
###Polymorphism: Allowing different item types to be handled through a common base type and to provide specialized behavior.

##Exception and Error Handling
###Validating constructor parameters.
###Using appropriate exceptions to handle invalid data.
###Handling invalid user input.
